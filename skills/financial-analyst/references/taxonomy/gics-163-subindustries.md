# GICS 163개 세부산업(Sub-Industries) 마스터 밸류에이션 매트릭스

## 3. 자동 프로파일 탐지 시스템(`profile_detector.py`) 연동 구조

파이썬 엔진(`profile_detector.py`)은 분석 대상 종목의 GICS Sector/Industry 메타데이터, 재무제표 항목(이자수익·보험수익 유무, R&D/매출 비중, 유무형자산 구성), 그리고 한글·영문 산업 키워드를 종합하여 위 163개 세부산업을 **5대 비즈니스 프로파일(`GENERAL`, `CYCLICAL`, `PLATFORM_SAAS`, `FINANCIAL_REIT`, `BIOTECH_RD`)**로 자동 라우팅합니다.
이를 통해 모든 종목 분석 시 해당 세부산업에 맞지 않는 왜곡 지표는 배제(`Excluded`)하고, 해당 산업의 본질적 해자를 결정짓는 핵심 KPI와 밸류에이션 배수만을 정밀 타격합니다.
