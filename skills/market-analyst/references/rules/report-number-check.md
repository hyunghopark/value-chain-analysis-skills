# 보고서 숫자 점검 규칙 (원본)

이 문서는 `market-analyst` 스킬로 작성된 마크다운 보고서에 언급된 모든 수치가 데이터 스냅샷 또는 본문 출처 인용(`[n]`)으로 입증되는지 사후 검증하는 원본 규칙입니다.

---

## 1. 개요 및 목적

보고서 본문 및 요약에 등장하는 모든 숫자(지수 종가, 등락률, 낙폭 %, VIX 수치, 국채금리 bps, 이격도 %, 날짜 등)는 환각(Hallucination)이나 자의적 왜곡이 없어야 합니다.

---

## 2. 검증 통과 기준 (Pass Criteria)

1. **Section 4 일치 (Exact Match)**:
   - 스크립트가 자동 생성한 Section 4 표의 숫자는 수정되어서는 안 되며, 스냅샷의 `section4.sha256` 해시와 보고서의 Section 4 해시가 일치해야 합니다.
2. **본문 인용 숫자 (Traceable Mention)**:
   - 본문(Section 1, 2, 3, 5, 6, 7, 8)에 기술된 숫자는 다음 중 하나를 만족해야 합니다:
     - 스냅샷 `values`에 기록된 값과 동일한 단위 및 허용 오차(소수점 1자리 이내)로 일치.
     - 외부 기사/공시 출처 번호(`[n]`)가 같은 문장 또는 같은 표 행에 기재되어 있고 `## References`에 완전한 URL이 존재함.
3. **[AI_TODO] 잔여물 부재**:
   - 미작성된 `[AI_TODO]` 플레이스홀더가 보고서에 남아있지 않아야 합니다.

---

## 3. 검증 스크립트 실행 및 종료 코드

```bash
python scripts/check_market_report_numbers.py "reports/<보고서파일명>.md"
```

- **Exit Code 0**: 점검 통과 (기록되지 않은 불일치 오류 없음)
- **Exit Code 1**: 점검 실패 (근거 없는 숫자, 조작된 Section 4, 형식 위반 등 수정 필요)
- **Exit Code 2**: 실행 실패 (파일 없음 등 환경 오류)
