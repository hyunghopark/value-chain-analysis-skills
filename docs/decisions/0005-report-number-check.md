# 0005. 보고서 숫자는 스크립트가 스냅샷·인용과 대조한다

- 상태: 채택
- 날짜: 2026-10-14
- 관련: [spec 002](../../specs/002-report-number-check/spec.md), 규칙 원본 `skills/financial-analyst/references/rules/report-number-check.md`

## 배경

investment-strategy에는 "숫자는 스크립트나 출처에서만", "직접 추정 계산 금지", "홈페이지 링크는 출처 아님", "Section 4 수정 금지" 규칙이 이미 있었지만 지키는지 확인할 수단이 없었다. 001 이후 첫 보고서를 측정하니 본문 숫자 약 270개를 사람이 대조해야 했고, 참고문헌 17개가 모두 홈페이지 주소였다. 또 001의 스냅샷에는 Section 4 숫자 694개 중 약 150개가 빠져 있었다(커버리지 테스트가 정해진 키 목록만 확인했다).

## 결정

1. **점검 도구 `check_report_numbers.py`를 financial-analyst에 둔다.** 스냅샷 모듈·규칙 원본과 같은 스킬이고, investment-strategy가 형제 스킬 스크립트로 부른다.
2. **직접 계산한 숫자는 근거 없음으로 본다.** 스냅샷 값의 합계·차이·변화율을 AI가 만들면 출처를 따라갈 수 없다(헌법 II). 같은 값의 단위만 바꾼 것(-39,334억 → -3조 9,334억)은 일치로 본다. 필요한 값은 스크립트가 직접 낸다.
3. **대조는 보수적으로 한다.** "잘못 통과 0건"(SC-001)을 우선해, 우연한 일치를 막는 규칙을 둔다.
   - 단위마다 대조할 스냅샷 경로 종류와 배율을 정한다(`%`는 비율 경로, `건`은 건수 경로, `조`는 금액·수급 금액 경로).
   - 작은 정수·0은 스냅샷과 직접 대조하지 않고, 같은 문장이 가리킨 Section 4 표에 같은 표기가 있을 때만 인정한다.
   - 유효숫자 두 자리 이하는 종목 문맥 안에서만, 근사 표현("부근")은 대조하지 않는다.
   - 처음 설계(모든 경로에 배율 적용, 작은 정수의 '약한 일치' 통과)는 검증 세트에서 "70%"↔배당수익률, "6배"↔EV/EBITDA, "107.4조"↔지수 거래량 같은 잘못 통과를 냈다. 규칙을 좁힌 뒤 같은 세트에서 잘못 통과 0건.
4. **Section 4 기준본을 스냅샷에 저장한다.** 보고서에 넣은 Section 4 원문을 `section4`로 덧붙여, 이후 수정을 줄 단위로(원래 값과 함께) 보여 준다. 해시만으로는 무엇이 바뀌었는지 알 수 없고, 별도 파일은 001의 "JSON 하나" 결정과 어긋난다. 저장은 Section 4를 실제로 조립하는 `generate_strategy_report.py`가 한다.
5. **Section 4의 모든 숫자를 스냅샷에 기록하고, 판정 기준값도 남긴다.** 표에 찍는 값을 그 자리에서 기록한다(`snap_display`). 판정 기준값은 코드 상수(`THRESHOLDS` 등)로 모아 판정 코드·설명 문구·스냅샷 `rules.*`가 같은 값을 쓴다. 규칙 문서를 파싱해 읽는 방식은 깨지기 쉬워 쓰지 않았다.
6. **남은 문제는 보고서에 사유와 함께 기록하면 통과로 본다.** 점검 도구는 보고서를 고치지 않는다(FR-014). AI가 `--section` 블록을 참고문헌 뒤에 넣고 사유를 적으며, 개수가 바뀌면 다시 만들게 한다. 문제가 0건일 때까지 막는 방식은 오탐 하나로 작업이 멈춰 택하지 않았다.
7. **기사 대조는 로컬 선택 실행이다.** 국내 사이트 접속이 불안정하고 유료·차단이 있어 CI에 넣지 않는다(헌법 기술 제약). 확인하지 못한 출처는 통과가 아니라 `unverifiable`이다.
8. **CI 테스트는 네트워크 없이 돈다.** 실제 데이터 출처에 접속하는 테스트는 `network` 표시를 달아 CI에서 빼고 로컬에서 실행한다(001에서 들어온 테스트 2개 포함).

## 결과

- 장점: 검토 대상이 '근거 없음' 목록으로 줄고, 숫자 규칙 위반을 스크립트가 먼저 찾는다. Section 4 → 스냅샷 대응이 상시 점검된다.
- 단점: 작은 정수·두 자리 숫자는 Section 4 표를 밝히지 않으면 근거 없음으로 나와 작성자가 참조를 붙이거나 사유를 적어야 한다. 정확도는 사람이 확정한 검증 세트(T013)로만 보장된다.
- 대조 규칙(제외 범주, 경로 종류, 단위 배율, 별칭)을 바꾸면 규칙 원본·코드·테스트를 같은 커밋에서 고친다. 테스트가 규칙 원본의 표와 코드 상수를 비교한다.
