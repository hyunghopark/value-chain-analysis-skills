# Value Chain Analysis Skills

Antigravity 에이전트를 위한 산업 밸류체인 분석 및 금융/기업 가치평가 전문 스킬 저장소입니다.

## 📦 포함된 스킬 (Skills)

### 1. `value-chain-analyzer`
- **버전**: v1.1.0
- **설명**: 산업 및 기술의 전체 생태계를 체계적으로 분석하는 스킬
  - 전방(Upstream), 중방(Midstream), 후방(Downstream) 구조 분해
  - 핵심 소재, 부품, 장비 및 주요 벤더 식별
  - Mermaid 다이어그램 자동 생성 및 표준 분석 보고서 출력

### 2. `financial-analyst`
- **버전**: v2.0.0
- **설명**: 상장 기업의 재무 건전성 및 밸류에이션(Valuation) 정밀 분석 스킬
  - 실시간 주가/밸류에이션 지표(PER, PBR, EV/EBITDA 등) 수집
  - 최근 분기 실적 및 어닝 서프라이즈 분석
  - 피어(Peer) 그룹 상대 가치 평가 및 목표 주가 컨센서스 정리
